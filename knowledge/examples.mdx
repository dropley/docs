# Example Projects

These example projects demonstrate different ways to use Dropley. Each one is a complete, working project that you can inspect and learn from.

## Basic HTML

A minimal single HTML page with inline CSS. Best starting point for understanding how Dropley serves single-file projects.

[View files](/examples/basic-html/)

## HTML with Assets

A single HTML page that loads Water.css from a CDN and adds inline styles. Demonstrates how to use an external stylesheet in a single-file project.

[View files](/examples/html-with-assets/)

For publishing steps, see [How to Share an HTML File Online](/knowledge/publishing-html).

## ZIP Project

A two-file project with `index.html` and `styles/main.css`. Shows how the HTML entry page loads a stylesheet through a relative path.

[View files](/examples/zip-project/)

For packaging and publishing steps, see [How to Upload a ZIP and Publish a Static Website](/knowledge/publishing-zip).

## Markdown to HTML

A static HTML page that uses the CDN-hosted marked library to render embedded Markdown in your browser. Demonstrates browser-side JavaScript in a static Dropley artifact.

[View files](/examples/markdown/)

## Client-review landing page

A polished, self-contained landing-page prototype with inline CSS and no build step. Use it to inspect a completed static output before sharing a preview with a client.

[View files](/examples/client-review-landing-page/)

For the end-to-end workflow, see [How to Share a Website Prototype With a Client](/knowledge/sharing-prototype-with-client).

## Static component-library export

A small, multi-file component-library preview with local CSS and JavaScript assets. It models the shape of a completed static export: an `index.html` entry page plus relative assets that work without a development server or build command.

[View files](/examples/storybook-static-export/)

This is a static export example, not a Dropley integration with Storybook or a replacement for its development tooling. To publish a comparable export, upload the complete folder or ZIP with `index.html` at its entry point. See [Publishing a ZIP Static Website](/knowledge/publishing-zip) for packaging and [Troubleshooting](/knowledge/troubleshooting) if local assets do not load after publishing.

## AI report dashboard

A fictional multi-file delivery report with local CSS and JavaScript assets. It is a public, temporary static report, not a live private dashboard. Inspect its `index.html` entry page before you package your own folder or ZIP.

[View files](/examples/ai-report-dashboard/)

For publishing steps and common asset failures, see [How to Publish an AI-Generated HTML Report or Dashboard](/knowledge/publishing-ai-html-reports), [How to Upload a ZIP and Publish a Static Website](/knowledge/publishing-zip), and [Troubleshooting](/knowledge/troubleshooting).
